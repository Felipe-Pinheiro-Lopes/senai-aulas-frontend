## 🧭 Contexto da Disciplina

O desenvolvimento Front-end é um **requisito estratégico**, fundamental para a competitividade empresarial. Envolve a **arquitetura de software** — como diferentes partes se interligam para melhorar as aplicações. Atualmente, boa parte das aplicações web modernas utiliza algum framework Front-end, pois as empresas precisam desenvolver interfaces rápidas, organizadas e fáceis de manter.

## 💡 O que é Desenvolvimento Front-end?

O Front-end é a camada de uma aplicação com a qual o **usuário interage diretamente**. É responsável pela criação das interfaces, organização visual dos elementos, experiência do usuário (UX) e comunicação com os sistemas responsáveis pelo processamento dos dados.

Tópicos abordados ao longo da disciplina:

- Definição de escopo, prototipação e UX;
- Conceito e importância no desenvolvimento web e UX/UI;
- Validação de ideias, refinamento de usabilidade e iteração;
- Uso de softwares de prototipação e desenvolvimento de projetos;
- Arquitetura de um site;
- Introdução ao versionamento e deploy;
- Introdução ao JavaScript (Vanilla JS).

### 🟨 Introdução ao JavaScript (Vanilla JS)

- **O que é?** Linguagem de script interpretada, essencial para o desenvolvimento front-end.
- **Vanilla JS:** JavaScript puro, sem dependências externas, base para todas as abstrações.
- **Importância:** Permite manipulação de páginas, comunicação com servidores e lógica de interface.
