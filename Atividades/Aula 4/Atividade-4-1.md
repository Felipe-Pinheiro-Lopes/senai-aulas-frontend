# Comparação de 10 Repositórios do GitHub que Consomem APIs Públicas (No-Auth)

> Os repositórios abaixo são **projetos de aplicações** (frontend / fullstack) que consomem APIs públicas sem autenticação.
> Cada projeto usa uma tecnologia moderna como Next.js, Vite, Angular, etc.

| # | Repositório (Nome + Link) | O que é o projeto | Tecnologias usadas | API consumida (endpoint de exemplo) |
| --- | --- | --- | --- | --- |
| 1 | [hoangsonww/The-Pokedex-Database](https://github.com/hoangsonww/The-Pokedex-Database) | Pokédex interativo de alto nível com grid paginado (48/página), busca ao vivo com debounce, favoritos persistidos em localStorage e transições animadas. Excelente referência de projeto production-grade. | **Next.js**, React Query, Tailwind CSS, Framer Motion, TypeScript | [PokéAPI](https://pokeapi.co/) — `https://pokeapi.co/api/v2/pokemon?limit=48` |
| 2 | [adrisons/react-pokemon](https://github.com/adrisons/react-pokemon) | Pokédex moderno com arquitetura feature-based, cache in-memory com TTL, code-splitting com React.lazy e roteamento client-side. Projeto de referência de boas práticas de organização de código. | **Vite** (React 19, TypeScript), Zustand v5, Tailwind CSS v4, shadcn/ui, React Router v6 | [PokéAPI](https://pokeapi.co/) — `https://pokeapi.co/api/v2/pokemon/pikachu` |
| 3 | [AndrewJBateman/angular-api-countries](https://github.com/AndrewJBateman/angular-api-countries) | Explorador de países com dados de população, capital, moedas e idiomas. Usa Angular Material para a UI e RxJS Observables para gerenciar as chamadas HTTP de forma reativa. | **Angular**, Angular Material, RxJS, HttpClient, TypeScript | [REST Countries API](https://restcountries.com/) — `https://restcountries.com/v3.1/all` |
| 4 | [samiraetc/pokedex](https://github.com/samiraetc/pokedex) | Pokédex clean e bem documentada, ideal para iniciantes. Cobre os requisitos clássicos: listagem, paginação, busca por nome e página de detalhes com stats do Pokémon. | **Vite** (React, TypeScript), Sass | [PokéAPI](https://pokeapi.co/) — `https://pokeapi.co/api/v2/pokemon?offset=0&limit=20` |
| 5 | [Mudi-Igbinoba/rest-countries-angular](https://github.com/Mudi-Igbinoba/rest-countries-angular) | App Angular de exploração de países com modo escuro, filtro por região, busca por nome e página de detalhes com países vizinhos. Demonstra uso limpo de serviços e Observables no Angular. | **Angular**, RxJS, Tailwind CSS, TypeScript | [REST Countries API](https://restcountries.com/) — `https://restcountries.com/v3.1/name/brazil` |
| 6 | [antfu/nuxt-movies-demo](https://github.com/antfu/nuxt-movies-demo) | Demo de catálogo de filmes criado pelo maintainer do Vite (Anthony Fu), usando o módulo `useFetch` do Nuxt para SSR de dados. Ótimo exemplo de boas práticas no ecossistema Vue/Nuxt. | **Nuxt.js** (Vue 3), TypeScript, Pinia, Tailwind CSS | [TMDB API (modo público)](https://www.themoviedb.org/documentation/api) — `https://api.themoviedb.org/3/movie/popular` |
| 7 | [lalezaris/pokedex](https://github.com/lalezaris/pokedex) | Pokédex que demonstra o uso de **Redux Toolkit com RTK Query** para gerenciamento de estado e cache de requisições, servindo como referência de arquitetura Redux moderna integrada ao Vite. | **Vite** (React, TypeScript), Redux Toolkit, RTK Query | [PokéAPI](https://pokeapi.co/) — `https://pokeapi.co/api/v2/pokemon?limit=151` |
| 8 | [mertokumus01/angular-country-explorer](https://github.com/mertokumus01/angular-country-explorer) | Explorer de países com Angular moderno (v21), design responsivo, filtros por região e pesquisa por nome com debounce. Usa a arquitetura baseada em serviços e os novos **Angular Signals**. | **Angular** (v21), Angular Signals, HttpClient, Tailwind CSS, TypeScript | [REST Countries API](https://restcountries.com/) — `https://restcountries.com/v3.1/region/americas` |
| 9 | [sveltejs/realworld](https://github.com/sveltejs/realworld) | Implementação oficial do projeto **RealWorld** em SvelteKit — clone do Medium com feed de artigos, perfis de usuário e comentários. Padrão da indústria para comparar frameworks front-end usando uma API REST padronizada. | **SvelteKit** (Svelte 4), TypeScript | [Conduit RealWorld API](https://realworld-docs.netlify.app/) — `https://api.realworld.io/api/articles` |
| 10 | [borisamico/pokedex-visual-app](https://github.com/borisamico/pokedex-visual-app) | Pokédex com design fiel à Pokédex da série animada, focado na experiência visual. Usa React com Vite e TypeScript, ideal para quem quer explorar animações e design system customizado sem API key. | **Vite** (React, TypeScript) | [PokéAPI](https://pokeapi.co/) — `https://pokeapi.co/api/v2/pokemon/1` |
